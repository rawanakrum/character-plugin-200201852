1. Close N8RO.
2. Disable old bridge if present:
   D:\N8RO_2\userPlugins\sim\rawan-character-bridge.dll
3. Copy this folder to:
   D:\N8RO_2\dev\samples\sim\rawan-four-motion-plugin
4. Copy human_animation_loop.lua to:
   D:\N8RO_2\data\resources\missions\human_animation_loop.lua
5. Run open-solution.cmd from the plugin folder.
6. Build Release | x64.
7. Confirm this file exists:
   D:\N8RO_2\userPlugins\sim\rawan-four-motion-plugin.dll
8. Relaunch N8RO.
9. In Scenario Editor -> Animation, add:
   Rawan Idle, Rawan Walk, Rawan Push, Rawan Climb
10. Apply.
11. Run simulation and open GLB viewer.
